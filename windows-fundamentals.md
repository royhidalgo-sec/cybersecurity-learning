## Key Takeaways

* NTFS controls access to files and folders through permissions.
* Windows uses users and groups to manage access to resources.
* UAC helps prevent unauthorized administrative changes.
* Task Manager and Resource Monitor can be used to investigate system activity and resource usage.
* Event Viewer is important for troubleshooting and security investigations.
* The Windows Registry stores configuration information for Windows, users, applications, and hardware.
* Windows services run background tasks required by the operating system and applications.
* Microsoft Defender and Windows Firewall provide built-in security protections.
* BitLocker provides full-volume encryption.
* TPM provides hardware-based security capabilities.
* VSS creates snapshots that can assist with data recovery.
