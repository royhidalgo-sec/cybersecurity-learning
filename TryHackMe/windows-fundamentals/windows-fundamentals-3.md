# Windows Fundamentals 3

## Overview

Windows Fundamentals 3 focuses on built-in Windows security features and technologies used to protect the operating system and its data.

## Windows Update

Windows Update provides operating system updates that can include:

* Security patches
* Bug fixes
* Feature updates
* Driver updates

Keeping Windows updated is important because security vulnerabilities may be fixed through updates.

## Windows Security

Windows Security provides a central interface for several Windows security features.

It includes areas such as:

* Virus & threat protection
* Firewall & network protection
* App & browser control
* Device security

## Microsoft Defender Antivirus

Microsoft Defender Antivirus provides built-in protection against malware and other threats.

It can perform different types of scans, including:

* Quick scan
* Full scan
* Custom scan
* Offline scan

## Windows Defender Firewall

Windows Defender Firewall controls network traffic using configured firewall rules.

It can allow or block network connections depending on the configured rules.

Windows Firewall uses different network profiles:

* Domain
* Private
* Public

## App & Browser Control

App & Browser Control provides security features designed to protect users against potentially malicious applications, files, websites, and downloads.

## Device Security

Device Security contains hardware and virtualization-based security features designed to protect the system.

## TPM

TPM (Trusted Platform Module) is a hardware-based security component.

It can securely store cryptographic information and support security technologies such as BitLocker.

## BitLocker

BitLocker is a Windows feature that provides full-volume encryption.

It helps protect data if a storage device is lost or stolen.

BitLocker can use TPM to help protect encryption keys.

## Volume Shadow Copy Service

VSS (Volume Shadow Copy Service) allows Windows to create snapshots of files or volumes.

Shadow copies can allow applications and Windows features to access previous versions of data.

VSS can assist with recovery, but it should not be considered a replacement for backups.

## Key Takeaways

* Windows Update provides important security patches.
* Microsoft Defender provides built-in malware protection.
* Windows Defender Firewall controls network traffic.
* App & Browser Control provides additional protection against malicious content.
* TPM provides hardware-based security capabilities.
* BitLocker provides full-volume encryption.
* VSS creates snapshots that can assist with data recovery.
